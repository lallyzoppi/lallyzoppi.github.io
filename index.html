Cyclone Harry Sardinia

Cyclone Harry affected Sardinia between 19 and 22 January 2026, producing extreme winds, heavy rainfall and coastal impacts. This project investigates the atmospheric dynamics of the event through meteorological data analysis and spatial wind variability assessment, combining data processing, geospatial methods and scientific visualization to characterize the cyclone's impact across Sardinia.

Python for data cleaning, visualization and statistical modelling
pdfplumber for extraction of text and tables from PDF files for data parsing and analysis
scipy.interpolate.griddata for interpolation over scattered data points
cartopy.crs for map projections and coordinate reference systems for geospatial data
cartopy.feature for geographic features such as coastlines, borders, and land/ocean layers

Sardinia Wildfire Risk Assessment Using Machine Learning

In Mediterranean environments such as Sardinia, wildfire occurrence is influenced by high temperatures, dry conditions, vegetation stress and atmospheric dynamics. This project investigates wildfire risk patterns using machine learning techniques. The analysis combines ERA5 meteorological reanalysis, NASA MODIS FIRMS satellite fire observations and geospatial information to model spatial variability in wildfire susceptibility.

Python data analysis and visualization
ERA5 meteorological data
NASA FIRMS satellite observations
joblib for efficient serialization of Python objects
json JSON encoding and decoding
LightGBM (LGBMClassifier) gradient boosting classifier for ML tasks
